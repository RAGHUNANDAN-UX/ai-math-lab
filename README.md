**AI Math Lab** is an interactive educational application that demonstrates how mathematical concepts power modern machine learning. Built with Python and Streamlit, it brings together four hands-on AI experiments where users can explore models, change parameters, observe predictions, and understand the mathematics behind each result.

The project connects classroom mathematics with practical artificial intelligence through visualisations and interactive experiments.

## 🧠 Explore the Four AI Modules

### 1. Handwritten Digit Recognizer
Explore how machine learning models identify handwritten digits using the scikit-learn digits dataset.

**Models included:**
- k-Nearest Neighbours (k-NN)
- Logistic Regression
- Multi-Layer Perceptron (Neural Network)

**Interactive experiment:** Select a test image, introduce noise, compare model predictions, and inspect class probabilities.

**Mathematics demonstrated:** Euclidean distance, vectors, softmax, probability, cross-entropy, and neural-network learning.

### 2. Sentiment Analysis AI
Explore how a text-classification model identifies positive and negative sentiment from sentences.

**Technology:** CountVectorizer and Multinomial Naive Bayes.

**Interactive experiment:** Enter a sentence, inspect the model's prediction and word-level influence, and teach the model additional examples during your session.

**Mathematics demonstrated:** Probability, Bayes' theorem, conditional probability, and Laplace smoothing.

### 3. Train an AI Live — Gradient Descent
Watch a simple machine learning model learn a relationship between study hours and marks.

**Model:** Linear regression trained using gradient descent.

**Interactive experiment:** Adjust the learning rate and training steps, move through the training process, observe the loss curve, and try a prediction.

**Mathematics demonstrated:** Linear equations, mean squared error, partial derivatives, gradients, matrices, and the normal equation.

### 4. K-Means Clustering
Discover how an unsupervised learning algorithm groups data points without being given category labels.

**Algorithm:** K-Means clustering.

**Interactive experiment:** Change the number of clusters, data spread, and random seed. Explore the cluster centroids and elbow-method graph.

**Mathematics demonstrated:** Euclidean distance, arithmetic mean, squared distance, and optimisation.

| Mathematical concept | Where it is used |
|---|---|
| Vectors and linear algebra | Digit recognition and model calculations |

## 💻 Run the Project Locally

### Prerequisites
- Python 3.10 or newer
- Git (optional, for cloning the repository)
- Internet connection for installing dependencies

### Step 1 — Clone the repository

```bash
git clone https://github.com/RAGHUNANDAN-UX/ai-math-lab.git
```

### Step 2 — Open the project folder

```bash
cd ai-math-lab
```

### Step 3 — Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4 — Start the application

```bash
streamlit run app.py
```

The application will open in your default web browser. If it does not, use the local URL displayed in the terminal.

## 🎓 Learning Outcomes

By exploring this project, students can:

- Understand the mathematical foundations of machine learning.
- Compare different classification algorithms.
- See how training parameters affect model behaviour.
- Interpret predictions, probabilities, and visualisations.
- Understand supervised and unsupervised learning.
- Apply Python libraries to practical mathematical problems.

## ⚙️ Notes

- The digit recognizer uses the built-in scikit-learn digits dataset.
- The sentiment classifier starts with a small set of example sentences; additional sentences can be added during the current application session.
- The marks-prediction and clustering modules use generated demonstration data.
- This is an educational demonstration, not a production-grade prediction system.
